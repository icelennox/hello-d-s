# hello-d-s

First repository pushed from **DeepSeek Harness** over SSH.

## 关于

- 这是 `icelennox` 的第一个 GitHub 仓库
- 由 DSH 里的鲸宝自动初始化：`git init` → 首次提交 → 推送到 `main`
- 认证方式：SSH（`~/.ssh/id_ed25519`），全程没有使用账号密码

## 为什么叫 hello-d-s

用来验证从本机到 GitHub 的完整链路：

```
本地目录 ──git add/commit──▶ 本地仓库 ──SSH──▶ github.com/icelennox/hello-d-s
```
